# SOCHNO AUTO

**Жёсткий адаптивный автофиниш YouTube-превью для Adobe Photoshop.**

Открой готовое превью. Нажми **F6**. Получи обработку: свет, цвет, объём, текстуру и чёткость — без ручной настройки параметров.

Это локальный скрипт с анализом изображения и проверкой пробного результата. Для каждой картинки он рассчитывает параметры заново. Интернет, подписки, Python и сторонние плагины не нужны.

## Что он делает

| Этап | Что меняется автоматически |
| --- | --- |
| Свет | Подъём тёмных средних тонов или сдерживание слишком светлых |
| Тени и света | Локальное проявление деталей без отсечения чёрной и белой точек |
| Контраст | Более сильная обработка плоских изображений, более сдержанная — контрастных |
| Цвет | Vibrance и насыщенность с учётом исходной красочности |
| Объём | Крупный локальный контраст |
| Текстура | Усиление деталей среднего масштаба |
| Чёткость | Мелкая резкость с радиусом, зависящим от размера холста |
| Шум | Оценка высокочастотного шума, ослабление резкости и мягкое сглаживание при необходимости |
| Контроль результата | Пробный рендер в Photoshop; снижение силы при избытке новых пересветов, провалов и перенасыщения |

## Установка — один раз, по шагам

**Ничего писать в терминале не нужно. Файлы кода редактировать не нужно.**

1. На странице этого репозитория нажми зелёную кнопку **Code**, затем **Download ZIP**.
2. Открой «Загрузки», найди скачанный ZIP. Нажми на него правой кнопкой → **Извлечь всё** → **Извлечь**.
3. Открой распакованную папку. Внутри должны лежать **SOCHNO_AUTO.jsx** и **INSTALL_SOCHNO.jsx**. Оставь их рядом. Не запускай установку прямо из архива.
4. Запусти **Adobe Photoshop**.
5. В верхнем меню Photoshop нажми **Файл → Сценарии → Обзор…**. В английском интерфейсе: **File → Scripts → Browse…**.
6. В окне выбора файла открой распакованную папку, выбери **INSTALL_SOCHNO.jsx** и нажми **Загрузить / Открыть**.
7. Если появится вопрос про конфликтующие клавиатурные сокращения — нажми **Нет**. Затем закрой сообщение «SOCHNO AUTO установлен» кнопкой **ОК**.

Готово. Установщик больше запускать перед каждым превью не нужно.

Установщик копирует основной скрипт в пользовательскую папку данных и создаёт набор **SOCHNO AUTO** в панели **Окно → Операции**. Перезапуск Photoshop не нужен.

Если Photoshop предложит удалить конфликтующее сочетание клавиш у новой операции, нажми **«Нет»**, чтобы сохранить F6 для SOCHNO. Эта клавиша будет запускать обработку вместо стандартного вызова панели «Цвет». Можно также убрать сочетание и запускать операцию кнопкой ▶.

Если F6 уже назначена другой твоей операции, измени сочетание в параметрах операции SOCHNO. На некоторых клавиатурах нужна **Fn + F6**.

## Каждое новое превью — что именно нажимать

1. Открой свой PSD, PNG или JPG в Photoshop. Убедись, что активна вкладка нужного превью.
2. Собери макет и включи те слои, которые должны быть на итоговой картинке.
3. Если сейчас редактируешь текст или трансформируешь объект, сначала заверши редактирование галочкой в верхней панели.
4. Нажми **F6** и подожди. Во время работы могут кратко переключаться временные вкладки — это анализ и пробный рендер.
5. Готово: в панели слоёв появится группа **SOCHNO AUTO | ЖЁСТКИЙ АВТОФИНИШ**. Процент в её названии показывает автоматически выбранную силу.
6. Отключи и включи **глазок слева от этой группы**, чтобы увидеть «до / после». Не переключай случайные исходные слои: они не отвечают за весь эффект.
7. Если результат подходит, сохрани PSD через **Ctrl+S** и экспортируй картинку обычным способом. Скрипт сам не нажимает «Сохранить».

**Поменял текст или картинку после обработки? Снова F6.** Старый результат обновится, а не усилится второй раз.

**Не понравилось? Ctrl+Z.** Или выключи глазок всей группы SOCHNO.

### Если F6 ничего не делает

1. Попробуй **Fn + F6**, если у тебя ноутбук или клавиатура с мультимедийными клавишами.
2. Открой в Photoshop **Окно → Операции** (английский интерфейс: **Window → Actions**).
3. Раскрой набор **SOCHNO AUTO** маленькой стрелкой слева.
4. Выбери операцию **SOCHNO — ЖЁСТКИЙ АВТОФИНИШ** и нажми треугольную кнопку **▶** внизу панели. Это запускает ту же автоматическую обработку.
5. Если набора нет, повтори установку через **INSTALL_SOCHNO.jsx**. Если F6 открывает панель «Цвет», сочетание могло быть удалено в предупреждении установщика — пользуйся ▶ или назначь клавишу в параметрах операции.

### Запуск без установки

- **Файл → Сценарии → Обзор → SOCHNO_AUTO.jsx**.
- В Windows можно дважды нажать **RUN_SOCHNO.vbs** рядом с основным JSX при открытом Photoshop.

## Как устроен результат

Появляется отдельная группа **SOCHNO AUTO** со снимком видимого макета, смарт-фильтрами и корректирующими слоями.

- **Глазок группы** — до / после.
- **Непрозрачность группы** — общий уровень эффекта, если захочется поправить его вручную.
- **Ctrl+Z** — отмена запуска одним шагом.
- **Повторный F6** — анализ исходных слоёв и замена предыдущего результата; обработка не накапливается.

Это финишный снимок композиции. После изменения текста, картинок или слоёв снова нажми **F6**, чтобы обновить обработку. Не переименовывай технический слой `SOCHNO_SOURCE_v1`: по нему скрипт узнаёт собственный результат.

Скрипт не сохраняет и не экспортирует документ автоматически. Исходные слои и цветовой профиль сохраняются. Для YouTube используй экспорт с преобразованием в **sRGB**.

## Совместимость

- **Проверено:** Photoshop 2026, версия 27.4.0, Windows.
- RGB, **8 или 16 бит**.
- Один обычный холст или **одна монтажная область**.
- Для нескольких монтажных областей вынеси нужное превью в отдельный документ.
- Основной JSX использует ExtendScript. Другие версии Photoshop и macOS пока не проверены; VBS предназначен только для Windows.

В проверках на холсте 1280 × 720 прогон занимал примерно **8–20 секунд**. Время зависит от компьютера, размеров, числа слоёв и количества пробных рендеров.

## Частые вопросы

| Что случилось | Что делать |
| --- | --- |
| JSX открывается как текст | Выбирай его **из Photoshop через Файл → Сценарии → Обзор**, а не двойным щелчком в Проводнике |
| Установщик просит положить файлы рядом | Полностью распакуй ZIP; основной скрипт и установщик должны находиться в одной папке |
| Не видно панели слоёв | **Окно → Слои** или F7 |
| Не вижу разницы | Найди именно группу **SOCHNO AUTO** и переключай её глазок. На уже обработанном исходнике прирост может быть меньше, чем на тусклом |
| Эффект слишком сильный | Выдели всю группу SOCHNO и уменьши её непрозрачность. Это необязательно: стандартный запуск полностью автоматический |
| После правки текста вижу старый текст | Нажми F6 ещё раз: группа хранит финишный снимок предыдущего макета |
| Ошибка про режим | **Изображение → Режим → RGB**, затем **8 бит/канал** или **16 бит/канал** |
| Ошибка про монтажные области | Оставь нужное превью в отдельном документе с одной монтажной областью |
| Нужно обновить скрипт | Скачай новый ZIP, распакуй и снова запусти INSTALL_SOCHNO.jsx. Набор SOCHNO будет заменён актуальной версией |

## Как работает адаптация

1. Исключается предыдущая группа SOCHNO, создаётся временная копия видимого макета.
2. В sRGB анализируется небольшая выборка пикселей: яркость, распределение тонов, насыщенность и доля предельных значений. Шум отдельно оценивается по гистограмме высокочастотной составляющей в исходном масштабе.
3. Рассчитываются параметры теней/светов, кривой, красочности и трёх масштабов детализации.
4. Photoshop строит пробный результат. Если выбранные пороги превышены, выполняется до трёх попыток с меньшей силой.
5. На исходный документ переносится отдельная группа обработки. При ошибке скрипт пытается откатить запуск и закрывает временные документы.

Проверка работает по уменьшенной выборке и не гарантирует отсутствие каждого локального артефакта. Уже потерянные детали она не восстанавливает.

## Про CTR

SOCHNO помогает сделать готовое изображение ярче и выразительнее. Он **не гарантирует рост CTR**, не оценивает смысл сюжета, не переписывает текст и не меняет композицию. Это адаптивный алгоритм обработки, а не нейросеть. Результат стоит смотреть также в размере карточки YouTube.
