# Проверки SOCHNO AUTO 1.3.0

Дата: 14 сентября 2026 года. Та же среда и те же два превью, что для 1.2; рендеры на копиях PSD.

- `node tests/policy.js` — **107** проверок. Новое: насыщенный неон со средней яркостью ~0,38 получает подъём < 5 и тени < 10, тусклое изображение той же яркости — подъём > 15; насыщенность ≥ 10 и выше для тусклых цветов.
- Покомпонентная диагностика 1.2 (по очереди выключался каждый дочерний слой группы, экспорт sRGB): слой 02 снижал цветность колеса 0,420 → 0,376 и удваивал пересвет в белое 2,4% → 5,1%; слой 03 поднимал яркость 0,341 → 0,361.
- Подбор 1.3 на тех же двух превью: Blend If «Этот слой» 200/250; защита плотности для подъёма 1,0; для теней 0,8; насыщенность +8.
- Колесо 1.3: яркость 0,344, цветность 0,400, colorfulness (Hasler–Süsstrunk) 0,500 → 0,521, пересвет в белое 2,4% (как в исходнике), одна проба, 12 с.
- Карта 1.3: яркость 0,520, цветность 0,446, colorfulness 0,561 → 0,582, пересвет в белое 6,2% (исходник 6,3%, 1.2 — 9,3%); сработала цветовая защита (3 пробы, colorGuard 0,61), 22 с.

# Проверки SOCHNO AUTO 1.2.0

Дата: 14 сентября 2026 года. Среда: Windows, Adobe Photoshop 2026, RTX 4070 SUPER.

- `node tests/policy.js` — **104** проверки. Новое: жёлтый и красный диапазоны не сдвигаются к оранжевому; перегрузка жёлтых или зелёных ослабляет слой зелени, перегрузка только красных — нет; 4% новых цветных пересветов не проходят контроль.
- Реальные рендеры в Photoshop через COM (`DoJavaScript`) на **копиях** рабочего PSD 1280×720 с одной монтажной областью; оригинал не менялся. Два превью: «Новая карта» (персонаж, карта, заголовок) и «Колесо фортуны» (яркий интерфейс, фиолетовый неон).
- Оба прогона: одна проба, контроль пройден, непрозрачность 100%, 12 секунд.
- Карта: chroma 0,421 → 1.1: 0,438 → 1.2: 0,456; R−B −0,046 → −0,025 → −0,051 (пожелтение 1.1 устранено). Доля пикселей с каналом ≥0,99: 28,7% → 35,4% → 37,7% — исходник уже насыщенный; визуально в размере карточки 320×180 заметных плоских пятен нет.
- Колесо: R−B +0,069 → +0,047 → +0,030; провалы в чёрное (max канал < 0,03) 7,3% → 11,9% → 11,3%. Новые провалы — контуры текста, волосы и складки худи: эффект крупного локального контраста, в 1.2 оставлен.
- «Выделить предмет» (`autoCutout`, sampleAllLayers) на карте: маска ≈100% кадра за 1,6 с, на колесе рамка на весь кадр. Отделение героя по маске не включено.
- Визуально сравнены исходник, 1.1 и 1.2 в 640×360 и 320×180.

Не проверено в 1.2: 16 бит, CMYK-отказ, шумное превью, повторная полная интеграция `tests/photoshop.jsx` (изменения не касаются переноса слоёв).

# Проверки SOCHNO AUTO 1.1.0

Дата: 10 сентября 2026 года. Среда: Windows, Adobe Photoshop 2026 / 27.4.0.
Рендеры выполнялись в реальном Photoshop на локальных копиях PSD. Пользовательские изображения и пути к ним не входят в репозиторий.

## Автоматические проверки

`tests/policy.js` — 100 проверок чистой логики. Запускается через `node tests/policy.js` или через «Файл → Сценарии → Обзор» в Photoshop. Изображения не изменяет.

- Раздельное распознавание всех шести основных оттенков. Проверено также в ExtendScript, где поведение вложенных условных выражений отличается от современного JavaScript.
- Нулевая цветовая обработка нейтральных изображений.
- Ослабление цвета не снижает свет и детализацию; ослабление света не меняет цветовую защиту.
- Для тусклых изображений выбирается более сильный Vibrance, для шумных — меньшая резкость.
- На тёмном насыщенном изображении сохраняется полный подъём средних тонов.
- Кривая монотонна и остаётся в пределах 0–255.
- Неизменённое изображение проходит контроль; превышение порога новых белых пикселей — нет.

`tests/photoshop.jsx` — интеграционные проверки. Для полного набора открой RGB-превью с одной монтажной областью и запусти этот файл через «Обзор». Скрипт работает на копиях, закрывает их без сохранения и возвращается к исходному документу. Журнал и PNG создаются в папке `SOCHNO-tests` внутри системной временной папки; для другого пути можно задать `$.global.SOCHNO_TEST_OUTPUT`.

Проверены:

| Сценарий | Результат |
| --- | --- |
| Реальный PSD 1280 × 720, одна монтажная область, дополнительная группа вне неё, выделение | Сохраняются порядок, родительские группы и видимость всех исходных слоёв, а также выделение |
| Замена результата версии 1.0 и повторный запуск 1.1 | Одна группа результата, одинаковые исходная и итоговая статистики |
| Группа пользователя с похожим именем без технического маркера | Сохраняется |
| Один шаг отмены | Возвращает предыдущую группу результата |
| Искусственная ошибка после скрытия старой группы | Восстанавливаются её видимость и контекст документа, временный документ закрывается |
| Обычное цветное превью | Финальный контроль пройден, непрозрачность 100% |
| Ослабленные цвет и контраст | Контроль пройден после двух проб, цветовая защита 78%, свет сохранён полностью |
| Затемнённое превью | Контроль пройден; отдельно перепроверено после уточнения подъёма тёмных тонов |
| Добавленный монохромный гауссовский шум | Включено сглаживание, ослаблен цвет; итоговая непрозрачность 60%, контроль пройден |
| RGB 16 бит | Битность и профиль сохранены, контроль пройден |
| Чёрно-белое изображение в RGB | Цвет не добавляется, контроль пройден |
| CMYK | Запуск отклонён без добавления группы |
| Принудительно ужесточённый контроль для проверки крайнего случая | Итоговая непрозрачность достигает 0%, статистика совпадает с исходником; под группой сохранён оригинал, а не пустой холст |

На этих проверках обычные проходы занимали около 12–22 секунд, тусклый вариант — 26 секунд, шумный с несколькими проверками — 44 секунды. Это измерения одного компьютера, не обещание времени для других файлов.

Экспорты обычного, тусклого, тёмного и итогового сравнительного превью проверены визуально. Установщик и формат F6-операции не менялись относительно версии 1.0; обновляется основной JSX по прежнему пути. После перезапуска Photoshop проверен запуск через установленную F6-операцию: она создаёт видимую группу версии 1.1 с шестью слоями и непрозрачностью 100% на тестовом PSD.

## Ограничения

- Проверена указанная версия Photoshop на Windows; macOS и другие версии не проверены.
- Даже для финального рендера статистика рассчитывается по уменьшенной выборке. Она не гарантирует отсутствие каждого локального ореола, пересвета или цветового артефакта.
- Цветовой баланс и оценка шума — эвристики. Скрипт не распознаёт лица и не восстанавливает потерянные детали.
- Не измерялся CTR, не проводился эксперимент с публикацией на YouTube.
- F6 может пересекаться с другими сочетаниями; порядок установки и запуска описан в README.
